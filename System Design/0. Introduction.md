
4 Pillars of Good Design - 
- Scalability, 
- Maintainability, 
- Efficiency, 
- Reliability

3 Key Elements - 
- Moving Data, 
- Storing Data, 
- Transforming Data

CAP Theorem / Brewer's Theorem: Guidance principle that helps us balance trade-offs between three key components - 
- Consistency - All nodes in a system have same data at the same time, change reflected in all systems
- Availability - System is always operational and responsive to requests
- Partition Tolerance - System's ability to continue working even if network partition occurs
According to this theorem, Systems can achieve any of the two things at a time

SLO - Service Level Objectives, provide how much will be the uptime and what will be the performance

SLA - Service Level Agreements, minimum level of service we're committing to provide

Reliability - Ensuring Systems work consistently

Fault Tolerance - Preparing for when things go wrong

Redundancy - Ensuring when one system fails, there is another one ready to take its place

## Speed Measurement
Improving one can sacrifice the other.

### Throughput  
How much data our system can handle over a certain period of time. 
- Server Throughput - Measured in Request Per Second(RPS)
- DB Throughput - Measured in Queries Per Second (QPS)
- Data Throughput - Measured in Bytes per Second (B/s)

### Latency  
How long it takes to handle a single request
